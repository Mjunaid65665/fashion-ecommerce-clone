🛍️ Fashion E-Commerce Website (Frontend Clone)

A modern and responsive fashion e-commerce website clone built using HTML, CSS, and Bootstrap.
This project focuses on clean UI design, reusable product cards, and a responsive layout suitable for real-world e-commerce platforms.

📌 Project Overview

This project is a frontend clone of a fashion e-commerce website.
It showcases a professional product layout using different card designs, responsive grids, and modern UI components.

The goal of this project was to:

Practice real-world e-commerce layouts

Improve Bootstrap grid and card components

Build responsive and clean UI

Create reusable product card designs

🚀 Features

Responsive layout for all screen sizes

Multiple product card designs

Modern fashion-style UI

Navigation bar with menu items

Product sections with grids

Hover effects on cards and buttons

Clean and organized code structure

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Custom styling and layout

Bootstrap 5 – Responsive grid and components
